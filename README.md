# 🏠 Rental Management System

## 📌 Overview

The Rental Management System is an Android-based mobile application designed to simplify the process of renting and managing properties. The application provides a digital platform where **property owners (landlords)** can list rental properties and **users (tenants)** can search, view, and save properties based on their requirements.

This system reduces the need for physical visits to real estate offices by offering an easy-to-use interface with advanced search options. It improves efficiency by automating property listing, searching, wishlist management, and user profile handling, making the rental process more organized, transparent, and accessible.

---

## ✨ Features

### 👤 User Authentication
- User registration
- Secure login system
- Validation for correct and incorrect login credentials

### 🏘 Property Management (Owner)
- Add property with details such as:
  - Property image
  - Property name
  - Location and city
  - Rent amount
  - Security deposit
  - Property type (House, Flat, 1-BHK, 2-BHK, PG/Hostel, etc.)
  - Availability date
  - Description
  - Contact number
- View uploaded properties (My Properties)
- Update property details
- Delete property listings

### 🔍 Property Search (User)
- Search properties using:
  - City
  - Minimum and maximum price
  - Property type
- View search results based on user input
- View detailed property information

### ❤️ Wishlist
- Add properties to wishlist
- View favorite properties separately
- Remove properties from wishlist

### 👤 Profile Management
- View user profile
- Update profile information
- Logout functionality

### 📱 User Interface
- Splash screen
- Home screen with role-based options
- Clean and user-friendly UI
- Smooth navigation between activities
